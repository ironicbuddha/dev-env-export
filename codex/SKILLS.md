# Codex Skills

Reusable skills are owned by the public Skill Hub, not this repository. Apply
the selected Carlo Baseline profile with:

```bash
./scripts/14-install-codex-skills.sh
```

The Hub projects one selected set through `~/.agents/skills`,
`~/.codex/skills`, and `~/.claude/skills`. Do not copy system skills, local
agent state, or unreviewed machine skill directories into this repository.
