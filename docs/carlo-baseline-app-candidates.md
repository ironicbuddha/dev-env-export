# Carlo Baseline App Candidates

This is a selection list, generated from the current `/Applications` folder.
Delete any candidate you do **not** want Carlo Baseline to install on a fresh
Mac. Keep the entries you want considered for the profile; a follow-up will map
the remaining apps to safe, supported installers before changing the bootstrap.

This list does not install, remove, or update any app.

## Selection notes

- Prefer a supported Homebrew cask only when it represents the intended app
  and has a usable macOS application bundle.
- Keep apps requiring personal licences, sample libraries, vendor accounts, or
  substantial content downloads as explicit manual first-run work unless there
  is a safe, documented unattended path.
- Do not add credentials, login state, plugins, or user content to the
  bootstrap.
