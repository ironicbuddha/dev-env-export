# MCP Catalogue

This directory is a manually applied catalogue, not a default MCP setup. The
bootstrap installs no MCP servers and writes no MCP configuration.

Prefer a standalone CLI or a selected Skill Hub skill where it offers the same
capability. Add an MCP server only for a concrete MCP-only need, using the
provider's documented authentication flow and 1Password for secrets. Record
the deliberate choice in the relevant project rather than copying machine state
into this repository.
