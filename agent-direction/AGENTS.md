# Agent Guidance

Read [constitution.md](constitution.md) first. It is the project's delivery
contract.

- Follow the repository's local instructions and existing conventions.
- Keep changes narrow, test behavior changes, and preserve unrelated work.
- Keep secrets, credentials, and personal configuration out of version control.
- Record meaningful architectural decisions in a short ADR or equivalent note.
- Ask before actions that require external authority or materially expand scope.

If this starter does not fit the project, edit it deliberately; do not grow a
generic policy bundle by default.
